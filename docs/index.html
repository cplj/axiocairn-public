Axiocairn · 0.2.0

Reconcile evidence before repeating an action.

Inspect an existing operation against its original local SQLite intent and receipt stores. Use the Python SDK, CLI, or loopback HTTP API. Recovery queries receipts and can update local intent state; it never executes the original action.

Get started

Requires Python 3.11 or newer. Install from Git (Git is required until PyPI availability):

python3 -m venv .venv && .venv/bin/python -m pip install git+https://github.com/cplj/axiocairn-public

Read the state

COMPLETED means matching effect evidence was observed. Use axiocairn verify --receipts DIR to check a file-object evidence bundle offline. UNKNOWN and other unresolved results require evidence review. An HTTP 200 response alone does not mean completion.

Real local Temporal, Inngest and Restate workers can write caller-selected files to an HTTP object store and reconcile lost acknowledgements. Legacy SQLite tools remain simulated. No live SaaS provider adapter, evidence authentication, concurrency guarantee, distributed exactly-once execution, or arbitrary rollback. Comparative runtime measurements are unavailable.
